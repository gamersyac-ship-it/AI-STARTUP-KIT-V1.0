# ADR-001: Governance by Workflow

## Status

Accepted

## Context

The framework requires a reusable, professional delivery model for AI-assisted software work. Without defined gates, teams may skip validation, produce inconsistent outcomes, or release artefacts that are not properly reviewed.

## Decision

The repository will enforce a sequential and documented delivery workflow: CEO → Product Manager → CTO → FullStack → QA → Security → DevOps → Documentation → Deploy.

## Consequences

- Benefits: stronger traceability, better quality, reliable release control.
- Trade-offs: more formal process and more governance overhead.
- Follow-up: departments must keep their documentation synchronized.
