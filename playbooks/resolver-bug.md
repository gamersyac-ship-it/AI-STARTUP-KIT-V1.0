# Playbook: Resolver un bug

## Objetivo

Corregir un defecto con trazabilidad, evidencia y bajo riesgo de regresión.

## Pasos

1. Reproducir el problema y documentar el contexto.
2. Confirmar la severidad y el impacto.
3. Asignar responsable de corrección y priorización.
4. Implementar la mínima corrección con prueba de regresión.
5. Validar con QA y Security cuando aplique.
6. Registrar el cambio y la causa raíz.
