# Playbook: Crear una API

## Objetivo

Definir una API segura, mantenible y consistente con las reglas del framework.

## Pasos

1. Definir el endpoint y el contrato esperado.
2. Validar seguridad, autorización y esquema de entrada.
3. Implementar el servicio con separación clara de responsabilidades.
4. Documentar request y response esperado.
5. Ejecutar pruebas de integración y casos de error.
6. Revisión final de estabilidad y observabilidad.
