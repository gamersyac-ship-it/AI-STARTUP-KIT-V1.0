# Playbook: Crear una pantalla

## Objetivo

Diseñar e implementar una pantalla cuya experiencia de usuario sea clara, accesible y consistente.

## Pasos

1. Definir el usuario, el propósito y el estado de la vista.
2. Alinear flujo con Product Manager y CTO.
3. Implementar subdividiendo responsabilidades y reutilizando componentes.
4. Revisar acceso, validación y feedback visual.
5. Validar accesibilidad, comportamiento y calidad funcional.
