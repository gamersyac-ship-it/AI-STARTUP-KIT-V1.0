# Playbook: Crear una funcionalidad

## Objetivo

Transformar una necesidad de producto en una entrega revisable, verificable y operable.

## Pasos

1. Recibir y priorizar la idea desde Product Manager.
2. Validar alcance, usuarios y criterios con el negocio.
3. Revisar arquitectura y riesgos con CTO.
4. Desarrollar la funcionalidad con el flujo de FullStack.
5. Ejecutar validación funcional con QA.
6. Revisar seguridad con Security.
7. Preparar la entrega con DevOps.
8. Registrar documentación y resultados.
9. Desplegar solo si el flujo completo está cerrado.
