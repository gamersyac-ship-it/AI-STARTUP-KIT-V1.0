# Playbook: Realizar un deploy

## Objetivo

Aplicar una entrega validada y documentada con el menor riesgo posible.

## Pasos

1. Confirmar que QA ha aprobado la entrega.
2. Confirmar que Security ha pasado revisión.
3. Confirmar la evidencia de despliegue y rollback.
4. Ejecutar la liberación mediante pipeline o procedimiento documentado.
5. Verificar salud y observabilidad post-deploy.
6. Registrar conclusiones y cierre operativo.
