# Project Definition

## Framework Name

AI-STARTUP-KIT

## Purpose

AI-STARTUP-KIT is a reusable software engineering framework for building startups and SaaS products with Claude Code/OpenCode inside VS Code. It is designed to simulate a real AI-assisted software company operating with documented roles, governance, delivery criteria, and technical guardrails.

## Intended Use

- Create new enterprise-style product organizations.
- Drive product and engineering decisions with documentation.
- Support reliable AI-assisted software development.
- Reuse the same governance model on future initiatives.

## Success Criteria

- A project can be understood without relying on tribal knowledge.
- The implementation flow remains consistent across departments.
- Quality, security, and delivery standards remain enforceable.
