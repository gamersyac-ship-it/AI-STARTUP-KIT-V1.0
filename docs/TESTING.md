# Testing

## Intent

Testing is a delivery guarantee, not a final optional step. Critical business and technical behavior should be validated with evidence before release.

## Test Philosophy

- Validate real behavior and release-critical flows.
- Keep tests understandable and maintainable.
- Test the product contract and the critical failure paths.
- Ensure regression protection for quality-sensitive changes.

## Coverage Expectations

- Unit tests for isolated logic.
- Integration tests for contracts and dependencies.
- Validation of user-facing and security-sensitive workflows.
- Release evidence tied to approved acceptance criteria.
