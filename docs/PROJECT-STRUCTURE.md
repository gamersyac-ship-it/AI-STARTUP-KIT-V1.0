# Project Structure

## Repository Intent

The repository is organized into shared operating layers so that product, technology, governance, documentation, and release evidence remain connected.

## Key Areas

- `.claude/`: organizational operating guidance and cross-cutting system documentation
- `agents/`: role-based execution profiles
- `company/`: company-level governance and operating documents
- `docs/`: technical and project documentation
- `memory/`: reusable institutional knowledge, constraints, and context
- `reviews/`: quality, security, performance, and release checklists
- `templates/`: reusable document shapes for delivery work
- `project/`: project-specific implementation area
