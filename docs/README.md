# AI-STARTUP-KIT Documentation

## Overview

This documentation set describes the reusable operating model for AI-assisted software delivery across startups and SaaS teams.

## Document Map

- [API.md](API.md): API contract and design expectations
- [DATABASE.md](DATABASE.md): data model, schema and migration guidance
- [DEPLOYMENT.md](DEPLOYMENT.md): environment and release process
- [CHANGELOG.md](CHANGELOG.md): release and change history
- [CONTRIBUTING.md](CONTRIBUTING.md): contribution expectations
- [ARCHITECTURE.md](ARCHITECTURE.md): system architecture reference
- [SECURITY.md](SECURITY.md): security posture and process
- [TESTING.md](TESTING.md): testing model and validation standards
- [STYLEGUIDE.md](STYLEGUIDE.md): writing and document style guidance
- [PROJECT-STRUCTURE.md](PROJECT-STRUCTURE.md): repository structure expectations

## Repository Relationship

- [.claude](../.claude) hosts company-wide documentation and governance guidance.
- [company](../company) holds operating policy, workflow, and delivery standards.
- [memory](../memory) preserves architecture context, constraints, and historical decisions.
- [reviews](../reviews) provides evaluation and release gates.
- [templates](../templates) offers reusable delivery artifacts.
- [standards](../standards) defines technology-specific best practices.
- [playbooks](../playbooks) captures step-by-step execution procedures.
- [decisions](../decisions) stores ADRs for important architecture choices.
