# Contributing

## Mission

This repository is a reusable framework for professional AI-assisted software delivery. Contributions must preserve maintainability, traceability, and alignment with the operating workflow.

## Expectations

- Follow the documented workflow and review order.
- Keep all changes traceable to a requirement, ADR, or approved idea.
- Update relevant documentation when behavior, architecture, or delivery process changes.
- Prefer small, deliberate, well-reviewed changes.

## Review Requirements

Every contribution must be reviewed by the responsible departmental owner, and the final delivery must remain consistent with the quality gates.
